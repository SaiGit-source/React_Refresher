Functional Components
A component is a reusable function that returns the UI.
Simplest type of component is a JavaScript function that returns JSX
function UserName() {
    return <h3>John Doe</h3>
}
what it is returning is only one root element and so it is valid

Props: We can pass data to components via components {props} or {name, email}

Hooks are special built-in functions that let functional components manage state and use other React features. 
Most commonly used hook is useState() lets component store values that change over time like Counter. When data in the state changes, the component re-renders
useEffect() for running side-effects like fetching backend/API data, useRef() for keeping a reference value without triggering re-renders unlike useState()
useContext() for sharing data between components without passing manually {props}
