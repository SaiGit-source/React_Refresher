Components are reusable

JSX looks like HTML but works inside JavaScript (JS)
JSX allows mixing HTML-like tags and JavaScript expression inside curly braces {} return <h2>Welcome to {appName}!</h2>


Functional Components
A component is a reusable function that returns the UI.
Simplest type of component is a JavaScript function that returns JSX
function UserName() {
    return <h3>John Doe</h3>
}
what it is returning is only one root element and so it is valid

Props: We can pass data to components via components {props} or {name, email}

Hooks are special built-in functions that let functional components manage state and use other React features. 
Most commonly used hook is useState() lets component store values that change over time like Counter. When data in the state changes, the component re-renders
useEffect() for running side-effects like fetching backend/API data, useRef() for keeping a reference value without triggering re-renders unlike useState()
useContext() for sharing data between components without passing manually {props}


Forms: signing in, submitting an order, 
each input is connected to a piece of state and that's how React controls the form values and easier to make changes also
Event handler handles form submission (like a button click)


Event handlers allow components to respond to user actions like clicking a button or typing in a field
You can pass a function directly to an event prop, like onClick or onChange


Rendering lists: Store data in array and use method map() to iterate array and generate JSX for each item and display on UI
we need to <li key={movie.id}> key prop and React needs this to update the list when new items are added


Working with Styled components: CSS files, Inline styles, Libraries
Styled components can handle hover effects, media queries or theming directly inside the component
