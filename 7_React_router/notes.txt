React router setup

say we want to display some page on a different route say /about, we need to add routing to our application

react-router-dom is a package that does for us
npm install react-router-dom 

go to App.jsx, add react router logic
import {createBrowserRouter, RouterProvider} from 'react-router-dom'

const routes = [{
  path: '/',
  element: <HomePage></HomePage>
}
]
Array of JavaScript object with specific properties, path: tells React router dom what path we are talking about and element: tells React router dom what to display when we are at that path

take those routes and create a browser router  const router = createBrowserRouter(routes)

Now pass this router as a prop into function App() return   Replace "<HomePage></HomePage>" and add "<RouterProvider router={router}></RouterProvider>"

Thats how we setup a react router

useNavigate():
It returns a function that allows you to change the URL.
Think of it like clicking a <Link> programmatically.

Link
import { Link } from 'react-router-dom';

function NavBar() {
  return (
    <nav>
      <Link to="/">Home</Link>
      <Link to="/about">About</Link>
    </nav>
  );
}

Advantages:
Easy to use in menus or inline links.
Automatically prevents full page reloads (SPA behavior).
Simple and readable in JSX.



import { useNavigate } from 'react-router-dom';

function LoginForm() {
  const navigate = useNavigate();

  const handleLogin = () => {
    // After successful login
    navigate('/dashboard');  // redirect programmatically
  };

  return <button onClick={handleLogin}>Login</button>;
}

What are Protected Routes in React?
A protected route is a route in your app that only certain users can access — usually authenticated users.
Example: /dashboard, /profile, /admin
Unauthenticated users trying to access a protected route are redirected to login or home page.
In React, this is usually done with React Router and a check for authentication.


How Protected Routes Work
You have a state or context that tells whether a user is logged in.
You create a wrapper component that checks this state.
If the user is authenticated, render the requested component.
If not authenticated, redirect to login or homepage.
